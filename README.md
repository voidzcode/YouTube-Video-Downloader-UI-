# YouTube-Video-Downloader-UI
Sick of finding sketchy sites to download a song or some videos to watch while on a road trip? Use this app i made!
This is a python based script that uses yt-dlp to install videos and audio from YouTube.com without fees or limits. This version is a UI version thats polished and much better than the original command line script.

This code is completely open-source and everyone is welcome to make their own versions BUT your code has to be open-source too and use the MIT licence.

# How to use?

Install the "app.pyw" file, the "install_and_build.py" file and the "installer.bat" file off this page.
Run the "installer.bat" file to install dependencies and executable.
Run the "YouTube_Downloader_GUI" file to open the downloader. (takes a couple of seconds to load up)

The app is completely free, unlimited and has no ads or donation nags.
